# AI 社交媒体自动化桌面工具 — 产品文档

> 日期：2026-10-20 · 版本：v1.0（设计定稿，用户已批准） · 配套文档：[技术文档](2026-10-20-ai-social-media-agent-tool-tech.md)

## 1. 定位与目标用户

**定位：自用工具优先**。不设计多租户、付费与团队协作；架构上不主动封闭未来商业化路径，但不为其增加当前成本。

**目标用户画像**：

> 个人创作者 / 独立开发者，同时在 2 个以上平台（首发：小红书、B站）运营图文账号，
> 有稳定内容领域（如技术科普、AI 工具测评）。痛点：选题耗神、写作耗时、多平台手动分发繁琐，
> 且希望账号内容风格统一、有个人辨识度。

该画像的推论：把两个平台的发布做到稳定可靠，优先于覆盖更多平台。

**核心动线**：配置一次 Agent → 每天 Agent 自动调研选题并生成内容 → 用户在草稿箱花约 10 分钟审阅 → 确认后自动发布。

## 2. 核心功能（MVP）

### 2.1 功能清单

**内容生产链（自动化）**

1. **热点调研** — 定时/手动触发，汇总各平台热榜，Agent 按领域相关性打分选题。
2. **内容生成** — 选题 → 大纲 → 成文；小红书笔记体 / B站专栏体各一套模板；写作前从全局记忆召回本人历史帖作为风格样例。
3. **配图生成** — 文生图 API 生成封面图，每篇 1~3 张。

**人机协作边界（唯一必经人工环节）**

4. **草稿审核箱** — 人工审阅、行内编辑、驳回；驳回理由沉淀为 Agent 偏好。

**发布与账号**

5. **自动发布** — 确认后经真实浏览器自动发布，结果（含错误分类）回写。
6. **账号管理** — 扫码登录、会话保持、健康面板展示各平台登录态。

**支撑系统**

7. **Agent 工作台** — 创建/配置 Agent：人设、内容领域、语言风格、目标平台、发布节奏。
8. **三层记忆** — 单次运行上下文 / Agent 偏好 / 全局历史帖库；被用户大幅改写的帖子自动降权，不再作为风格样例。
9. **运行日志** — 每次流水线的完整执行记录与发布历史。

### 2.2 MVP 明确不做（非目标）

视频管线、发布后数据统计回流、多用户/云同步、自动评论互动、多账号矩阵养号、验证码自动绕过。

## 3. 主界面 UI 规格

视觉基准：Visual Companion 定稿渲染（frost 主题完整合成稿）。

### 3.1 布局：卡片网格仪表盘

顶栏 + 3 列卡片网格（无侧栏）。卡片：热点雷达 / 流水线状态（五阶段 pill 流）/ 草稿箱（活跃高亮）/ 账号健康 / 记忆库 / 发布历史（跨列走势图）。

### 3.2 视觉体系：深色极客风 × 玻璃质感

- 底色 `#05070d`；卡片毛玻璃质感 + 渐变洗色 + 主题色 1px 描边；活跃卡片（草稿箱）带彩色 glow 提醒行动。
- 数字高亮：主题色渐变文字；状态灯：辉光圆点（绿=online / 琥珀=需重登）。
- 静态网格底纹：28px 细线网格。

### 3.3 主题系统

五变量配色（主色/辅色/点缀/成功/警告），运行时可切换。预置 6 套：ion / matrix / ember / synth / **frost（默认）** / mono。

### 3.4 动态背景

三团主题色光晕在底图上缓慢漂移；系统开启"减弱动态效果"时自动静止。

### 3.5 字体

中文标题/Logo 用宋体衬线（思源宋体 SemiBold）；数字/日志/时间戳用等宽字体。高级感来自两种气质的对比。

### 3.6 顶栏迷你轨道时钟

40px 轨道盘（三针 + 日进度环）+ HH:MM，位于顶栏右侧；配色随主题联动。完整版（含农历/问候语/驻留时长）预留为网格卡片选项，MVP 不展示。

## 4. 与竞品的差异点

| 竞品 | 它的定位 | 我们的差异 |
|---|---|---|
| Social Auto Upload（开源） | 只自动化"上传发布"环节，视频向 | 我们是调研→写作→配图→审→发全链路 Agent，且图文风格记忆为独有能力 |
| CreBee / 蚁小二类矩阵工具 | 企业多账号分发 SaaS，内容仍靠人写 | 个人创作者本地单机；内容由 Agent 产出；账号凭据不出本机 |
| AiToEarn（开源，最接近） | AI 批量生成 + 多平台分发，矩阵变现导向 | 记忆驱动的风格一致性 + 人工审核边界 + 适配器开放契约 |
| Memoraid（浏览器插件） | 网页摘要轻量发文 | 无定时任务、无多账号、无记忆 |

**一句话定位**：现有工具要么"帮你发"（分发工具），要么"帮你写一篇"（AI 写作工具）；没有工具在本地桌面上把"调研→写作→风格记忆→审核→发布"做成闭环，且风格随使用越来越像你自己。
